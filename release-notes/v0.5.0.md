A breaking release for Rust only. The `.esm` format stays at **esm 1.3.0**, and every document that loaded under 0.4.0 loads unchanged. Julia, Python, TypeScript and Go only gain features. The three Rust breaks are listed below with how to upgrade.

## Breaking changes

- **Rust: `SimulateError` has a new variant**, `RangeRestriction { code, message }` (#557). It is raised when a range-restricted or operator-restricted right-hand side is refused. A `match` over `SimulateError` without a `_` arm needs one more arm.
- **Rust: `ProblemOptions` has a new public field**, `runtime_array_parameters` (#561). Code that builds `ProblemOptions` with struct-literal syntax must set it, or end the literal with `..Default::default()`. `false` keeps the 0.4.0 behavior.
- **Rust: the `precision` module uses `Arc` instead of `Rc`** (#561). `precision::variable_precisions()` returns `Arc<VarPrecisions>`, and `precision::enter_env` takes one. Replace `Rc` with `Arc` at those call sites.

## Highlights

- **Range-restricted right-hand sides** (Julia and Rust, native compiler, #557). Build one operator's right-hand side and evaluate it over a tile of a horizontal decomposition, with halo cells read from an extended local array, or over a run-time list of lanes (cells or columns). Tiles' owned rows, assembled, equal the whole-domain right-hand side bit for bit. Four new error codes: `range_halo_insufficient`, `range_global_locality`, `range_selection_writes_incomplete` and `range_box_invalid`. In Python these calls raise `compiler_unavailable`.
- **A public, thread-safe right-hand side with forcing sets** (Julia and Rust, #561). `rhs_program` builds once. Rust's `RhsProgram`, `TileProgram` and `LaneProgram` are `Clone + Send + Sync`, and each thread evaluates with its own workspace. Forcing is passed to every call as an immutable, epoch-stamped `ForcingSet`. Warm calls allocate nothing. With `runtime_array_parameters`, gridded parameters become forcing slots, so they can change without a rebuild.
- **Julia tiles compile once** (#565). All tiles of an operator share the whole-domain program's generated code. On the regional-inflow test document, generated code shrank 14-fold and the first call fell from 852 s to 40 s.
- **Rust's native `solve` runs through `RhsProgram`** (#561), with no extra copy per call. Results are unchanged.

## Other changes

- Python 3.9 is no longer tested in CI (#563), because `ubuntu-latest` has no Python 3.9 build. The package still declares `requires-python = ">=3.9"`.
