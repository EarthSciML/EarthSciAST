A compatible release: no public API was removed or changed, and model results are unchanged.

## Highlights

- **The native compiler covers every operation the downstream EarthSciML models use**, in both Julia and Rust (#512).
- **Native runs threaded by default** in Julia and Rust, with results bit-identical to serial runs (#501). The Rust tape uses AVX2 by default. In Julia, Polyester is now a regular dependency rather than a weak dependency with an extension.
- **Native no longer falls back to slower evaluation at run time.** A rule it cannot compile is refused when the problem is built, not discovered mid-solve (#506).
- **Unit checking is more thorough** (#508). It now follows scoped references across mount edges, checks through the array operators (`index`, `reshape`, `transpose`, `concat`, `makearray`, `broadcast`, `faq`), and raises a base to a constant-expression exponent.
- **The `esm-narrative` command-line tool now ships with each release**, alongside `esm`, for Linux, macOS and Windows (#514).
- **The Linux binaries run on any glibc-based distribution from the last decade**, not just the newest, and now come for ARM64 as well as x86_64 (#516).
