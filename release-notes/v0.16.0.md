## Breaking changes

- **Typst prints word-named index sets upright (#806).** In a `faq` range row, an index set named by a word now prints `k in upright("lev")` instead of `k in italic("lev")`, which read as the product l·e·v. Each segment of a scoped set name follows the rule on its own: `upright("lev")"."upright("top")`, `a"."upright("bins")(k)`. A letter, a Greek name, the `x_i` shape and a formula print as in any name, and LaTeX is unchanged. Typst documents written by 0.15 still read. A Typst document written by this release with such a set **cannot be read by 0.15 or earlier**, which refuse the upright set name. The reader takes an upright set name only in the form the printer writes (an identifier of two or more characters that is neither a Greek name, the `x_i` shape nor a formula), so `upright("a")`, `upright("x_i")` or `upright("alpha")` in a set slot is refused.
