A patch release with additions to lane programs in Rust and Julia, a Julia build gap closed, and faster function calls in the Rust native tape. Nothing is removed or renamed. The `.esm` format stays at **esm 2.4.0**, and Python, TypeScript and Go have no code changes.

## New

- **Lane programs read an array `faq` at the lane's own cell** (#780, API_SPEC §5.8 "Lanes"; Rust and Julia). Two document forms that EarthSciIntegrator's planner writes were refused when building lane programs: a whole-array right-hand side `D(x) = faq{…}`, and a `makearray` whose region value is an array `faq` (every band field of a Jacobian document). Both now build. The value at a lane's cell is the `faq`'s body at that cell, so a runtime no longer has to rebuild lane programs from a rewritten copy of each document.
- **A time per lane** (#781, API_SPEC §5.8 "A time per lane"; Rust and Julia). Lane programs can take one time per lane, for integrators where each cell has its own step-size controller. Rust adds `LaneProgram::eval_times_into` and `eval_gathered_times_into`; Julia adds the method `rhs!(du, lanes, ws, u, aux, p, ts::AbstractVector, fs, cells, n)`. Lane `l` equals the whole-domain program at `cells[:, l]` and time `ts[l]`, bit for bit. With equal times the result equals the one-time call, which is unchanged.

## Fixes

- **Julia: a computed array bound to an array parameter is passed as a call argument** (#778). A definition whose array parameter was bound to a `makearray`, to a `faq` the build does not read element by element, or to a whole-array reference was refused at build with `E_TREEWALK_UNSUPPORTED_OP`. The array is now evaluated once per right-hand side in the caller and passed whole. The reference stays a call, and nothing is expanded or inlined. Rust and Python already ran these documents. New conformance fixture: `array_expression_forms/computed_array_argument`.

## Performance

- **Rust native tape: independent calls of one operator definition run as one batched execution** (#777). Calls of the same compiled function that don't depend on each other run together over all their frames. The frames share the decoded code, the index tables and the scratch space, and array arguments are read in place without copying. A function's constant section now runs once per context. Bodies with a branch region, a recurrence or their own per-instruction precision still run one frame at a time. A batch with enough work is still split across threads.
